# Ruptura F&F

App da equipe Genom: estoque da F&F – Taboão da Serra (rupturas e reposições), pré-pedidos de cada representante e geração da planilha de importação do Sales Farma (aba `Dados_pedidos`).

- Login: número do setor + senha (no primeiro acesso a senha é o próprio setor).
- Avisos no celular quando um produto entra ou zera, e quando um pré-pedido fica pronto.
- Dados no Supabase (projeto "Ruptura FF"). Este repositório só tem a parte pública do app.
